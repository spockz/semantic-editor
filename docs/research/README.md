# Research Questions & Spikes (Index)

This directory tracks open technical investigations, spikes, and design questions for `semedit`.

To conserve LLM context budget during pair-programming sessions, consult this index first. Only read the specific research file relevant to the immediate sub-problem.

Before creating an RQ, check whether an existing question already covers the investigation and update or extend it when the scope matches. Create a new RQ only for a materially distinct question with its own evidence and decision gate; do not split one continuing investigation into multiple records for convenience.
